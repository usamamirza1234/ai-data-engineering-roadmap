PHASE 1: Core Data Engineering + Python
Days 1-30
💡 Goal: Transition from Ruby to Python and build solid data engineering foundations. By end of Phase 1, you'll have a production-ready ETL pipeline on GitHub.
📅 Week 1: Python Fundamentals & Data Structures
Day 1: Python Basics & Setup
  • Install Python 3.10+, VS Code, and set up virtual environment (30 min)
  • Python syntax basics: variables, data types, operators (compare with Ruby) (1 hr)
  • Learn: Lists, tuples, dictionaries, sets - Python Tutorial (1.5 hrs)
  • Practice: Solve 5 basic problems on HackerRank/LeetCode (1 hr)
Day 2: Control Flow & Functions
  • If/else, loops (for, while), list comprehensions (1 hr)
  • Functions: def, args, kwargs, lambda functions (1 hr)
  • Error handling: try/except/finally (45 min)
  • Practice: Write 3 utility functions (data parsing, validation, transformation) (1.5 hrs)
Day 3: File I/O & Data Formats
  • Reading/writing files: CSV, JSON, text files (1 hr)
  • Working with pathlib for file paths (30 min)
  • Learn: json, csv modules in depth (1 hr)
  • Mini-project: Build a CSV to JSON converter with data validation (2 hrs)
Day 4-5: Pandas Fundamentals
  • Install pandas, numpy. Learn DataFrames & Series (1 hr)
  • Reading data: read_csv, read_json, read_excel (1 hr)
  • Data exploration: head, info, describe, shape, columns (1 hr)
  • Selecting data: loc, iloc, boolean indexing (1.5 hrs)
  • Data cleaning: handling nulls, duplicates, data types (2 hrs)
  • Practice: Clean a messy dataset (Kaggle) - handle missing values, outliers (2 hrs)
Day 6-7: Advanced Pandas & Data Transformation
  • GroupBy operations: aggregations, transformations (2 hrs)
  • Merging & joining: merge, concat, join (1.5 hrs)
  • Pivot tables and reshaping data (1 hr)
  • Apply, map, applymap for custom transformations (1 hr)
  • Mini-project: Analyze sales data - aggregations, joins, pivot tables. Push to GitHub (3 hrs)
📅 Week 2: SQL Mastery & Database Connections
Day 8-9: Advanced SQL
  • Review: SELECT, WHERE, JOIN, GROUP BY, HAVING (1 hr)
  • Window functions: ROW_NUMBER, RANK, DENSE_RANK, LAG, LEAD (2 hrs)
  • CTEs (Common Table Expressions) and subqueries (1.5 hrs)
  • Analytical queries: running totals, moving averages (1.5 hrs)
  • Practice: Solve 10 SQL problems on LeetCode/HackerRank (Medium level) (3 hrs)
Day 10: Python + SQL Integration
  • Install PostgreSQL locally or use Docker (30 min)
  • Learn: psycopg2 or SQLAlchemy for database connections (1 hr)
  • Pandas + SQL: pd.read_sql, to_sql methods (1 hr)
  • Practice: Load CSV to PostgreSQL, run queries, export results (2 hrs)
Day 11-12: PySpark Basics
  • Install PySpark, understand Spark architecture (1 hr)
  • SparkSession, DataFrames, basic operations (2 hrs)
  • Transformations vs Actions, lazy evaluation (1 hr)
  • Reading data: CSV, JSON, Parquet (1 hr)
  • Data transformations: select, filter, groupBy, agg (2 hrs)
  • Practice: Process large CSV file with PySpark (use public dataset) (2 hrs)
Day 13-14: ETL Script Development
  • ETL design patterns and best practices (1 hr)
  • Logging: Python logging module, log levels (1 hr)
  • Configuration management: config files, environment variables (1 hr)
  • Convert your Ruby ETL to Python (or create new one): Extract from API/CSV → Transform → Load to PostgreSQL (4 hrs)
📅 Week 3: AWS Cloud & Data Pipeline
Day 15-16: AWS Fundamentals
  • Create AWS Free Tier account (30 min)
  • Learn: IAM (users, roles, policies) - security best practices (2 hrs)
  • S3: buckets, objects, versioning, lifecycle policies (2 hrs)
  • Install AWS CLI, configure credentials (30 min)
  • Boto3 (AWS SDK for Python): upload/download files to S3 (2 hrs)
  • Practice: Create S3 bucket, upload dataset, set permissions (1 hr)
Day 17-18: AWS Glue & Data Processing
  • AWS Glue: Data Catalog, Crawlers, Jobs (2 hrs)
  • Create Glue Crawler to catalog S3 data (1 hr)
  • Write Glue ETL job using PySpark (2 hrs)
  • AWS Athena: Query S3 data using SQL (1.5 hrs)
  • Practice: Run Athena queries on your S3 dataset (1 hr)
Day 19-20: Lambda & Event-Driven Architecture
  • AWS Lambda basics: functions, triggers, execution (1.5 hrs)
  • Create Lambda function to process S3 events (2 hrs)
  • Lambda layers, environment variables, permissions (1 hr)
  • Practice: Trigger Lambda on S3 upload to validate/transform data (2 hrs)
Day 21: Data Warehousing Basics
  • Learn: Data warehouse concepts (star schema, fact/dimension tables) (1.5 hrs)
  • AWS Redshift OR Snowflake basics (choose one) (2 hrs)
  • Create Redshift/Snowflake trial account (30 min)
  • Design simple star schema for your project (1 hr)
📅 Week 4: Orchestration & Project Delivery
Day 22-24: Apache Airflow
  • Install Airflow locally (or use Docker) (1 hr)
  • Airflow concepts: DAGs, operators, tasks, dependencies (2 hrs)
  • Create your first DAG: simple data pipeline (2 hrs)
  • Operators: PythonOperator, BashOperator, S3Operator (2 hrs)
  • Task dependencies, XCom for data passing (1.5 hrs)
  • Scheduling, retries, alerts (1 hr)
